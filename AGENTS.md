## The rule that binds this port

**Byte-faithful to the reference, or a DOCUMENTED divergence — never a quiet
one.** `test/fixtures/parity.json` is generated by the PHP reference. Never
edit it by hand: regenerate it from the reference and commit the change
together with the code that matches it.

Three traps are already covered by the fixture. Do not "simplify" them away:

- **Bytes, not strings.** Spans, ids and lengths are UTF-8 byte values, as
  with PHP's `strlen`.
- **ASCII `\s` and `trim()`.** The reference's regexes have no `/u` flag, so
  JavaScript's Unicode `\s` and `.trim()` would change heading paths and ids.
- **Literal U+2028/U+2029 cannot appear in a regex literal.** Build such
  patterns from char codes.

## Security properties, each with a test that fails without it

- scope isolation in SQL (`test/scope.test.ts`);
- the acceptance policy;
- the overwrite guard, inside a caller's transaction too;
- trust immutability;
- retired text as evidence;
- erasure;
- serialised savepoints;
- FTS literals;
- the fence.

Every one of these was mutation-checked when it landed. Keep it that way.
